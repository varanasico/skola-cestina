# Vyjmenovaná slova

Webová aplikace pro procvičování i/y ve vyjmenovaných slovech. Viz [docs/PRD.md](docs/PRD.md) a [docs/IA.md](docs/IA.md).

## Vývoj

```bash
npm install
npm run dev      # vývojový server
npm run build    # produkční build
npm run preview  # náhled produkčního buildu
```

Stack: React + TypeScript + Vite, bez backendu. Pokrok a nastavení se ukládají do `localStorage` prohlížeče.
